# gate0 打标明细表（add-instant-mood-fit 2.1，供人工复核）

判据（客观动词法，对应 Gate 0 条件三）：条目**核心动作**是「留意 / 看 / 听 / 闻 / 感受 / 观察既有事物」→ **A 感知重定向**；核心动作是「做 / 换 / 买 / 试 / 去 / 改一件事」→ **B 边界内新鲜尝试**；感知与动作混合、难分主次 → **无标**（缺省中性，不参与心情软优先）。

复核方式：扫「判」列有无不服的条目，直接说 id 即可改。错标最坏结果只是该条心情软优先失效，不影响可抽性。
